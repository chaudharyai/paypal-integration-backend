# PayPal Integration Backend 🚀

### A Powerful Backend for PayPal REST API Integration 🌟

This project allows seamless interaction with PayPal's REST APIs, including creating orders, capturing payments, and handling webhooks. It's built to bypass frontend limitations and process server-to-server payments efficiently. 

---

## 🌟 Features

- **Create Orders**: Dynamically create PayPal orders with custom amounts.
- **Capture Payments**: Easily capture authorized payments with a single call.
- **Webhook Handling**: Process PayPal events like payment captures, refunds, and disputes.
- **OTP & Location Bypass**: Works with server-to-server API calls, avoiding region-specific issues.
- **Ready for Deployment**: AWS-ready and CI/CD pipelines enabled.

---

## 🛠️ Tech Stack

- **Backend**: Node.js + Express.js
- **API**: PayPal REST API
- **Environment**: AWS Lambda, Hostinger, or Local Testing
- **Tools**: Postman for API testing, GitHub Actions for deployment
